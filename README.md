درود . نسخه جدید با افزودن کد امنیتی کپچا فارسی منتشر شد

1- فایلهای موجود در پوشه file رابه پوشه html در ایزابل منتقل کنید :

```
/var/www/html/

```

2- فایل login.tpl را به پوشه  _common در قالب خود منتقل کنید . فرض میکنیم که پوسته فعلی ایزابل شما vitenant باشد . به مسیر زیر رفته و فایل را منتقل کنید :

```
/var/www/html/themes/vitenant/_common/

```

بعد از تغییر و در صورتی که صفحه لاگین تغییر نکرد ، از بخش تغییر پوسته ایزابل ، یکبار پوسته پیش فرض را به یک پوسته دیگر تغییر داده و مجددا پوسته اصلی خود را انتخاب نمائید .
